# SpanishChat — Scaffolded AI Language Learning

SpanishChat is a Django-based prototype exploring how generative AI can support language learning within a structured instructional experience.

Rather than asking beginners to engage immediately in an open-ended conversation with an AI chatbot, the application provides a progression from listening and controlled practice to more independent language use.

The project combines instructional design, interactive phrase construction, audio playback and AI-powered conversational practice.

## Learning Design

The experience follows three stages.

### 1. Listen and become familiar with the language

Learners encounter Spanish vocabulary and phrases, supported by audio playback to develop familiarity with pronunciation.

### 2. Construct and rehearse sentences

Using a structured word bank, learners combine words into simple sentences, explore grammatical patterns and listen to the resulting phrases.

This provides an intermediate step between recognising language and producing it independently.

### 3. Apply language in realistic conversations

Learners move into AI-powered roleplay scenarios, such as ordering in a café, where they practise communicating in Spanish and receive contextual feedback on their responses.

The underlying instructional principle is **scaffolding**: providing support during the early stages of learning and progressively increasing the learner's independence.

## Role of Generative AI

Google Gemini powers conversational practice and feedback.

The model is used to:

- Generate Spanish responses within a conversational scenario.
- Respond dynamically to learner input rather than following a fixed dialogue.
- Provide contextual feedback on the learner's Spanish.
- Support practice in situations that approximate everyday communication.

The distinction is intentional: **structured activities provide the learning framework, while generative AI enables flexible conversational practice** that would be difficult to achieve through predefined dialogue alone.

The prototype uses the `google-genai` Python SDK and is currently configured to use `gemini-3.5-flash-lite`.

## Features

### Phrase Practice

Structured practice designed to help beginners develop familiarity with Spanish sentence construction.

- Vocabulary and phrase practice.
- Interactive sentence construction using a word bank.
- Colour-coded grammatical elements.
- Audio playback for vocabulary and constructed phrases.
- A progression towards independent conversational practice.

### AI Conversation Practice

Learners practise Spanish in conversational scenarios supported by generative AI.

- Scenario-based roleplay, including restaurant conversations.
- Dynamic Spanish responses generated by Gemini.
- Contextual language feedback.
- Opportunities to apply vocabulary and sentence structures introduced during earlier practice.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Michaela2024/Spanish-conversation.git
cd Spanish-conversation
```

### 2. Create a virtual environment

On Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

On macOS or Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

The application uses the supported `google-genai` SDK rather than the deprecated `google-generativeai` package.

### 4. Configure your API key

Create a file named `.env` in the project root, alongside `manage.py`.

Add:

```env
GOOGLE_API_KEY=your_google_api_key_here
```

You can obtain an API key from [Google AI Studio](https://aistudio.google.com/app/apikey).

**Security:** Never commit your `.env` file or API key to GitHub. The `.gitignore` file excludes local environment configuration.

### 5. Apply database migrations

```bash
python manage.py migrate
```

### 6. Start the development server

```bash
python manage.py runserver
```

Open your browser at:

http://127.0.0.1:8000/

If port 8000 is already in use, you can run the application on another port:

```bash
python manage.py runserver 8001
```

Then visit:

http://127.0.0.1:8001/

## Using SpanishChat

### Phrase Practice

1. Open the application and navigate to Phrase Practice.
2. Explore Spanish vocabulary and grammatical structures.
3. Use the audio controls to hear pronunciation.
4. Construct simple phrases using the available words.
5. Listen to the completed phrases before moving to conversation practice.

### Conversation Practice

1. Navigate to Conversation Practice.
2. Start an available conversational scenario.
3. Read the AI-generated response in Spanish.
4. Enter your own response in Spanish.
5. Continue the conversation and review the contextual feedback.

The aim is to help learners move from supported sentence construction towards more spontaneous language production.

## Prototype Scope and Limitations

SpanishChat is an experimental application rather than a production-ready language-learning platform.

The current prototype demonstrates:

- A structured progression from listening to sentence construction and conversation.
- Integration of generative AI into a learning experience.
- Dynamic conversational roleplay.
- Contextual language feedback.
- Audio-supported practice.

Areas for further development include:

- Systematic evaluation of the accuracy and pedagogical usefulness of AI feedback.
- More robust management of conversation continuity.
- Broader coverage of learning scenarios.
- Learner progress tracking and longitudinal assessment.
- Accessibility, usability and security testing.
- Better handling of API errors, latency and operating costs.

A comprehensive learner performance assessment system has not yet been implemented.

## Product and Learning Design Considerations

The prototype explores several questions relevant to AI-enabled learning products.

### How much structure should precede an AI conversation?

An unrestricted chatbot can be intimidating for beginners. Structured practice allows learners to rehearse vocabulary and sentence patterns before applying them.

### Where does generative AI add educational value?

AI is most useful here when the learner moves beyond predefined exercises and needs a conversational partner capable of responding to varied input.

### What makes AI feedback trustworthy?

Generated feedback can be helpful, but it may also be inconsistent, overly corrective or pedagogically inappropriate.

A production implementation would require explicit quality criteria, representative test conversations and ongoing evaluation.

### How should learner progress be measured?

Completing an exercise or sustaining a conversation does not necessarily demonstrate learning.

A more mature product would distinguish activity, proficiency and measurable improvement over time.
